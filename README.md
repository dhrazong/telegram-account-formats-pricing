## Three formats, three different jobs

### TDATA folder

Telegram Desktop writes a `tdata` directory the first time you sign in. Sellers export that directory, zip it, and hand it over. You drop it into Telegram Desktop's data location and the client opens already signed in, with no SMS and no phone involved. This is a desktop-only format: Windows, macOS and Linux. It does nothing for a phone, and if you only own a mobile device, a TDATA listing is the wrong purchase regardless of price.

### session + JSON

These are the credential files that account managers and automation tools read. They're worth having if you're loading accounts into a tool that talks to Telegram's API. If you're logging in by hand, they add nothing over TDATA, which is why sellers usually bundle both in the same listing.

### Number plus code page

The seller gives you a phone number and a web page that displays whatever Telegram texts to that number. You enter the number in the app, request the code, read it off the page, and you're in. It works on any device, including a phone with no SIM in it.

The code page is a login aid, not ownership. You don't get the SIM, you don't get lasting access to that number, and the number itself can be recycled later. Your continued access rests on the password and the active sessions you control, which is exactly why the next section matters.

## The first ten minutes after delivery

1. **Sign in on the device you'll actually use.** Drag the tdata folder into Telegram Desktop, or enter the number and pull the code from the page. Don't test on a borrowed device and then wonder why the session list looks strange.
2. **End every other session.** Settings → Devices → terminate all other sessions. The seller, their supplier and anyone else holding a copy of the same export show up in that list until you clear it. This single step does more for the account's lifespan than any other.
3. **Change the cloud password.** If the listing came with a 2FA password, that password belongs to whoever set it up. Replace it. If there's no 2FA yet, set one, then store it somewhere that isn't the same note as the login.
4. **Test inside the warranty window, one account at a time, and screenshot.** Capture the successful login, the profile page and any error message, with timestamps. A dispute backed by screenshots from day one takes minutes. Without them it turns into a conversation about what you might have done wrong.

## What the price does not include

- **The SIM or long-term access to the number.** The code page is for logging in. It isn't a subscription to that number's messages.
- **Telegram Premium, if the account currently shows it.** That subscription isn't part of the sale and can lapse.
- **Readers.** Channel and group growth (post views, members, reactions, shares, story views) is a separate purchase on every store that sells it.
- **Top-ups on standard-tier growth orders.** Only the premium tiers come with a refill window.
- **Bans from mass messaging, bulk invites or bot activity.** Marketplaces across this segment put that outside warranty, and it's the most common way people lose accounts they bought an hour earlier.

## FAQ

**Can I change the password after buying?**
Yes, and you should, before anything else. Change the cloud password, then check Settings → Devices and kill every session that isn't yours.

**Will the original phone number be recycled?**
Possibly. The code page gives you login access, not the number. Once you've changed the password and ended other sessions, the number's fate stops mattering much, but any future code-based recovery will go to a number you don't control. Keep your own recovery email and password instead.

**Can I buy more than one?**
Yes. AccountBoy handles bulk through support rather than a published tier. Specialist marketplaces show stock and minimums on each listing and usually quote a better unit price at volume, so compare before buying thirty.

**Do I need a phone to use a TDATA account?**
No. That's the point of the format. Drag the folder into Telegram Desktop and you're in. If you need the account on a phone as well, you'll want a number with a code page or a session your tool can load.

**What if the account is dead when it arrives?**
It depends on the window attached to that specific product. AccountBoy replaces quality issues inside three days. Z2Market routes disputes through escrow and reviews unresolved claims, with a refund or replacement where the claim holds. AccsMarket's marker is 48 hours. In every case the outcome depends on evidence, so screenshot the failure the moment you see it.

## Before you pay, confirm two things

**The warranty line on that exact product.** Not the store's general policy, not the category description, the line on the item you're buying. Replacement or refund, and how many days. A $2 listing with 48 hours and a $3 listing with 14 days are not the same product, even when the titles match.

**The format against your device.** TDATA is desktop only. If the account has to live on a phone, you need a number with a code page or a session your tool can load. Getting this wrong is the most common reason a perfectly good account gets left unused.
